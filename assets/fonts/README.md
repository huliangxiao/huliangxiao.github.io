# Homepage fonts

These unmodified, locally hosted variable fonts are distributed under the
SIL Open Font License 1.1. Both families support weights 200–900 in upright
and italic styles. Source Serif 4 additionally provides optical sizing.

The main text WOFF2 files come directly from Adobe's official release repositories:

| Local file | Original source |
| --- | --- |
| `source-sans-3-normal.woff2` | [SourceSans3VF-Upright.ttf.woff2](https://github.com/adobe-fonts/source-sans/blob/release/WOFF2/VF/SourceSans3VF-Upright.ttf.woff2) |
| `source-sans-3-italic.woff2` | [SourceSans3VF-Italic.ttf.woff2](https://github.com/adobe-fonts/source-sans/blob/release/WOFF2/VF/SourceSans3VF-Italic.ttf.woff2) |
| `source-serif-4-normal.woff2` | [SourceSerif4Variable-Roman.ttf.woff2](https://github.com/adobe-fonts/source-serif/blob/release/WOFF2/VAR/SourceSerif4Variable-Roman.ttf.woff2) |
| `source-serif-4-italic.woff2` | [SourceSerif4Variable-Italic.ttf.woff2](https://github.com/adobe-fonts/source-serif/blob/release/WOFF2/VAR/SourceSerif4Variable-Italic.ttf.woff2) |

Copyright notices and complete license terms are included in
`source-sans-3-OFL.txt` and `source-serif-4-OFL.txt`.

The main text files retain their full upstream glyph coverage, including Latin.

`source-sans-3-navigation.woff2` is the unmodified Latin subset served by
[Google Fonts](https://fonts.gstatic.com/s/sourcesans3/v19/nwpStKy2OAdR1K-IwhWudF-R3w8aZejf5Hc.woff2)
for [the reference homepage](https://sypj-98.github.io/). Only the Contents
navigation uses this file, registered as `Source Sans 3 Navigation` with the
same 400, 500, and 600 weight declarations as the reference. This preserves
the reference's weight selection for its 700-weight Contents heading as well.
The existing `source-sans-3-OFL.txt` license also applies to this font.

All fonts are served locally, without depending on the Google Fonts CDN at runtime.
